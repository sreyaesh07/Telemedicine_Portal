# Telemedicine_Portal
# Telemedicine Slot Booking & Prescription Portal — Lab 1

## Problem Statement
Secure healthcare consultation portal enabling patients to book video 
consultations and receive digitally signed prescriptions.

## Deliverables
- `requirements.md` — 5 Functional + 2 Non-Functional Requirements
- UML Use-Case Diagram
- Use-Case Flow Specification for "Book Consultation Slot"

## Actors
- Patient
- Attending Physician


## Lab 2: Agile Backlog Creation & Sprint Simulation (Jira)


### Epics
- Doctor Discovery & Slot Booking
- Video Consultation
- Prescription Management

### User Stories
10 user stories created and linked to the above epics, covering booking, 
video consultation, prescription management, rescheduling, and notifications. 
(See `screenshots/epics-and-stories.png`)

### Story Points
Estimated using the Fibonacci sequence (2, 3, 5, 8) based on complexity.
(See `screenshots/story-points.png`)

### Prioritization
Stories ranked by business/security criticality — booking and identity 
verification stories set to Highest priority; supplementary features 
(e.g., prescription download) set to Medium.
(See `screenshots/priorities.png`)

### Sprints

- **Sprint 2**: Reschedule Consultation Slot, Notify Physician of New Booking — completed.
